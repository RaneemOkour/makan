# MAKAN | مكان
> Discover places. Meet people. Live the story.

## 🌿 Overview
**Makan** is an immersive local experience and discovery platform designed to connect travelers and locals with authentic places, stories, and people across Jordan.

> "There’s more to a place than a destination."

---

## 🧭 Core Pillars
- **📍 Places:** Uncovering destinations through community narratives.
- **✨ Experiences:** Local, handcrafted, and authentic activities.
- **👤 People:** Empowering local storytellers, guides, and artisans (Hosts).
- **📖 Stories:** Cultural context and living traditions.
- **🎥 Immersive Exploration:** Signature **Makan Flyover** visual previews.

---

## 🎯 Target Users
1. **Explorer:** Discovers, filters, books experiences, and saves favorites.
2. **Host:** Lists unique local experiences, manages bookings, and shares culture.
3. **Admin:** Platform moderation, host verification, and quality oversight.

---

## 🛠️ Tech Progression Roadmap
Makan is built progressively from foundational semantics up to full-stack production:

- [ ] **Phase 01: Semantic HTML & Accessibility** (Pure structure, forms, SEO, WCAG standards)
- [ ] **Phase 02: Modern Editorial CSS** (Jordanian heritage theme, responsive grid/flexbox)
- [ ] **Phase 03: JavaScript DOM & Web APIs** (Filtering, interaction, modal flyovers, state)
- [ ] **Phase 04: Component Architecture (React)** (Reusable components, dynamic routing)
- [ ] **Phase 05: Backend & Database** (REST APIs, relational data modeling, auth, bookings)
